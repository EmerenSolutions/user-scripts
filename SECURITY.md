# Security Policy

## Supported versions

Only the latest version of each userscript on the `main` branch is supported.
Userscript managers should receive updates from the `@updateURL` declared in
each installable source file.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for issues involving data
exposure, unsafe page injection, permission scope, or cross-origin behavior.
Do not include sensitive details in a public issue.

For ordinary bugs without security impact, open a GitHub issue and include the
script version, userscript manager, browser version, affected URL, and relevant
console output.
